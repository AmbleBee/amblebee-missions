# {name}

Mission packs for [AmbleBee](https://amblebee.com): little dates and adventures, one YAML file per mission.

- `missions/`: one folder per pack, each with a `pack.yaml` and its missions. Field reference: `missions/SCHEMA.md`.
- `tools/check_missions.py`: checks every mission (`python tools/check_missions.py`). It also runs on every push.

Made with the AmbleBee mission manager, which writes and checks missions in your browser.
